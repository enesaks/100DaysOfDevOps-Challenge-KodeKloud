### Task: Süreli (Geçici) Kullanıcı Oluşturma

**Amaç**
Projeye geçici olarak dahil olan bir personel için, belirlenen tarihte erişimi otomatik olarak kesilecek (Account Expiration) bir kullanıcı hesabının provizyonlanması.

**Adımlar**

* İlgili uygulama sunucusuna (App Server 2) SSH ile bağlanıldı:
```bash
ssh steve@stapp02
```

```
sudo useradd -e 2027-02-17 james
```
